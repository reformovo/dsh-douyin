# dsh-douyin

摸鱼抖音：一个 DSH 插件，在右侧边栏竖着一个接一个地刷抖音推荐流，Agent 干活的时候提示你把它调出来。

数据来自抖音 Web 端的推荐接口。Host 注册匿名 `ttwid`、生成 `msToken`，用本机的 a_bogus 签名器给每个请求签名；签名器是 `lib/abogus.js`，移植自 [dtk](https://github.com/Evil0ctal/Douyin_TikTok_Download_API) 的纯 Python 逆向实现（Apache-2.0），并用真实浏览器产生的签名样本（`fixtures/abogus_browser.json`）做过离线校验。

请仅用于个人学习与研究，内容版权归权利人所有。

## 功能

| 位置 | 内容 |
|---|---|
| 右侧边栏 | `摸鱼抖音` 标签页：一次一条视频，滚轮 / `↑↓` / 触摸上下滑，**一直往下刷，自动续页**；关掉再打开会接着上次的位置拉新的一批，不重播看过的 |
| 播放器 | 自动播放、循环、**点击画面或空格暂停/继续**、**进度条可点击/拖动**、静音开关（`M`）、进度与时长、点赞/评论/分享数 |
| 拖动跳转 | 松手后停在当前帧并转圈，Host 用 ffmpeg 从目标时间点重切一段流（约 1–2 秒，落点按关键帧对齐），因此不依赖浏览器的原生 seek |
| 头部 | `↻` 换一批：清空当前队列，重新拉一批；`头像` 打开账号面板 |
| 抖音账号 | 绑定浏览器里的登录 Cookie 后，推荐换成你自己账号的那一套 |
| 左侧栏底部 | `抖音` 按钮，一键打开 |
| 输入框上方 | Agent 运行时出现一行小提示：`打开` / `×`；播放器已在屏幕上时不出现 |
| 任务完成 | Agent 从运行变为空闲时自动暂停，画面上提示一句；点一下画面就继续 |

## 登录（可选）

匿名访客拿到的推荐是抖音给"没有账号的人"的那一套，很容易刷到广告或不相干的长视频。绑定自己的账号之后，同一个接口会按你账号的观看历史推荐。

### 一键登录（默认，不用复制）

在插件右上角点「登录」→「一键登录（打开抖音窗口）」：

1. 插件用自己的临时浏览器档案打开一个独立 Chrome / Edge 窗口，停在 `douyin.com`；
2. 你在那个窗口里点「登录」并用抖音 App 扫码；
3. 插件通过 DevTools 协议读回这个窗口的 Cookie，自动验证、绑定，然后关掉窗口、删除临时档案。

不会碰你日常浏览器的档案，不需要全盘访问权限，也不需要钥匙串。整个过程只多一个扫码动作。

- 窗口 5 分钟没完成会自动关闭；也可以随时点「取消」，窗口立即关掉。
- 没装 Chrome / Edge 时按钮会提示，并自动切到粘贴方式。

### 手动粘贴（备用）

从 DevTools 里复制整行 Cookie：打开 `douyin.com` 并登录 → F12 → Network → 刷新 → 点最上面那条 `douyin.com` 请求 → Request Headers 里的 `Cookie` 整行复制 → 粘贴、绑定。

真正需要的是 `sessionid`、`sessionid_ss`、`sid_tt`、`uid_tt`、`uid_tt_ss`，其余一起带上更稳；也支持直接粘贴 DevTools 里 Cookie 表格的多行内容。

### 两种方式共同的部分

- 校验：Host 拿这串 Cookie 请求 `/aweme/v1/web/user/profile/self/`，只有返回 `status_code=0` 且带用户信息才算绑定成功，粘错/过期会直接告诉你。
- 存储：只存在本机凭据库（`ctx.credentials` 的 `dsh-douyin/session` 记录），不写配置文件，不发给页面。
- 解绑：面板里点`解绑`，记录会被删除，推荐退回匿名；打开面板时还会做一次实时校验，过期会标红。

**为什么不做网页里的扫码**：抖音的二维码接口（`/passport/web/get_qrcode/`）对非浏览器请求直接返回风控错误 `4031`，`sso.douyin.com` 那条直接给反爬页面。所以扫码必须在真实浏览器窗口里完成——也就是上面的一键登录。

## 依赖

| 依赖 | 用途 | 缺失时 |
|---|---|---|
| Node ≥ 20 | 插件本体 | 无法加载 |
| `ffmpeg` | 拖动跳转时从目标时间点重切流 | 拖动仍会跳，但会失败；正常播放不受影响 |
| Chrome / Edge | 一键登录时打开扫码窗口 | 只能手动粘贴 Cookie |

macOS 上 `brew install ffmpeg` 即可。

## 结构

- **Host（`index.js`）**：`/api/douyin/{config,session,login,feed,media,cover}`。`session` 管理账号绑定，`login` 负责一键登录窗口；`feed` 走签名的 `tab/feed` 接口并归一化；`media` 与 `cover` 是同源代理（校验域名、转发 `Range`、封面内存缓存），页面拿不到签名、CDN 原始地址和 Cookie。
- **Client（`client.js`）**：注册侧边栏标签页类型 `douyin`、侧栏底部按钮、输入框上方的等待卡片。
- **签名（`lib/abogus.js` + `lib/sm3.js`）**：纯 JS，无第三方依赖。

## 配置

`cordis.patch.yml` 中 `douyin` 行的 `config`：

| 字段 | 默认 | 说明 |
|---|---|---|
| `autoPrompt` | `true` | Agent 运行时是否在输入框上方提示打开抖音 |
| `feedCount` | `8` | 每次请求的条数（抖音会自行裁剪） |

## 校验

```bash
node scripts/verify-sign.mjs   # 用真实浏览器签名离线校验签名器
node scripts/probe-feed.mjs    # 现场请求一次推荐流
node scripts/smoke-host.mjs    # 挂载 Host 路由，跑通 feed / media / cover / session
```

## 已知限制

- 抖音会改接口与签名，`version_code` / 签名器都可能需要跟着更新；失效时表现为 `feed` 返回非 0 或空列表。
- 推荐流里混有广告与图文，插件会过滤掉；某一页全是广告时会自动往后翻页。
- 拖动跳转会重新拉一段流（约 1–2 秒），不是即时的逐帧预览；落点对齐到目标前的关键帧，可能有几秒偏差。
- 没有登录态时不能点赞、关注、搜索；绑定了 Cookie 也只用于推荐，不做写操作。
- Cookie 会过期（通常几周到几个月），过期后头像还在、推荐会退回匿名——重新绑一次即可。
